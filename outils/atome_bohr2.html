Composition de l'atome

A = Z + N
Configuration électronique
Erreur fréquente : confondre Z et A. Z compte les protons, A compte les nucléons (protons + neutrons). Le nombre de neutrons ne se lit jamais directement sur le tableau : il se calcule, N = A − Z.
Vue 3D animée
Le modèle de Bohr est une image utile pour compter les électrons, pas une photo : les électrons ne parcourent pas de véritables orbites, ils occupent des zones de probabilité.
