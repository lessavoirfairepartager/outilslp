Nuage de brainstorming

Ecoute de la classe · nuage de mots + phrases en direct

Ce navigateur ne sait pas transcrire la parole. Ouvrez cette page dans Google Chrome ou Microsoft Edge (sur ordinateur), avec une connexion internet active.
Pret. Cliquez sur Demarrer l'ecoute.
Nuage de mots Cliquez un mot pour le garder. « Terminer » ne laisse que les mots gardes.
Phrases entendues Un clic : juste → a corriger → neutre. La croix supprime.
    Bon a savoir : la transcription passe par le navigateur et demande internet (cet outil n'est pas hors-ligne). La reconnaissance n'est pas parfaite : elle sert de brouillon a corriger avec la classe.
    Comment brancher le micro USB d'ambiance ?
    1. Branchez le micro USB, puis dans Windows → Parametres → Systeme → Son → Entree, choisissez-le comme peripherique d'entree par defaut. Le navigateur ecoute toujours le micro par defaut du systeme.
    2. Ouvrez cette page dans Chrome ou Edge, cliquez Demarrer l'ecoute et autorisez le micro quand le navigateur le demande.
    3. Parlez normalement : les mots remplissent le nuage, les phrases s'ajoutent dessous.
    4. Pendant le tri, cliquez les bons mots pour les garder, puis Terminer le nuage. Marquez les phrases justes / a corriger d'un clic.
    5. Plein ecran pour projeter, Imprimer / PDF pour garder une trace (nuage garde + phrases marquees).
